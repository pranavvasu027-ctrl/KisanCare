# KisanCare Mobile Services (Step 3 Scope)

This directory is reserved for:
- API client configuration (`apiClient.ts` with Axios/Fetch and `EXPO_PUBLIC_API_URL`)
- Authentication service (`authService.ts` with Supabase Auth integration)
- Crop recommendation service (`cropService.ts`)
- Disease vision AI upload service (`diseaseService.ts`)
- Soil intelligence service (`soilService.ts`)
- Market price API client (`marketService.ts`)
- Offline cache & persistence service (`storageService.ts`)

No backend calls or API integrations are implemented during Step 2.
