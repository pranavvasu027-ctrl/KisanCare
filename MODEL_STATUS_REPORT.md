# Model Integration Status Report

## 1. Crop Recommendation Model
* **Model Name and Purpose**: `crop_recommendation_mvp_v2`. Recommends crops based on district, season, and water availability.
* **Model Files and Dependencies**: `models/crop_recommendation/crop_recommendation_mvp_v2.pkl`, preprocessing pipelines, label encoders, and metadata JSON.
* **Input Requirements**: `district` (string), `season` (string), `water_availability` (string).
* **Expected Output**: List of recommendations containing `crop`, `predicted_area_frequency`, and `rank`. Includes filtered candidates with explanations.
* **Current Integration Status**: Fully functional within the `ml/` service and callable from the frontend via the `backend` proxy.
* **Execution Status**: The model executes successfully. The `PredictionPipeline` correctly initializes and loads the model.
* **Output Accuracy**: Outputs are generated by the actual LightGBM/RandomForest model using historical data constraints. It is not hardcoded.
* **Frontend Connection**: Connected to the `backend/` proxy which forwards to the `ml/` service. 

## 2. Cost/Profit Model
* **Model Name and Purpose**: `cost_profit_model`. Predicts expected cost and profit for a farm.
* **Model Files and Dependencies**: `models/model6_cost_profit/artifacts/cost_model.joblib`.
* **Input Requirements**: State, crop, irrigation details, labor costs.
* **Expected Output**: Predicted total cost and cost per hectare.
* **Current Integration Status**: Integrated in the `ml/` orchestration endpoints. Partially functional depending on feature availability.
* **Execution Status**: The orchestrator in `ml/routers/farms.py` can invoke this model.
* **Warnings**: Requires DB context (Digital Twin state) to execute accurately.

## 3. Market Price Model
* **Model Name and Purpose**: `market_price`. Predicts crop prices in specific mandis (markets).
* **Current Integration Status**: Missing in backend. A dummy API endpoint `/api/v1/market-price/` was created in `backend/app/api/endpoints.py` to prevent the frontend from crashing. 
* **Execution Status**: Hardcoded fallback data is returned. The actual model inference is not currently connected to the backend.

## Summary
The primary `crop_recommendation` model works perfectly. The `cost_profit_model` is structurally integrated via an orchestrator but relies on complex database state. The `market_price` model is currently disconnected.
